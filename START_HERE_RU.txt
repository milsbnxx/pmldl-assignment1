НАЧНИ ОТСЮДА — ЧИСТЫЙ ЗАПУСК

Этот архив — новая чистая версия проекта. Не копируй в неё файлы из старой папки.

0. Останови старую версию:
   - в терминале с Airflow нажми Ctrl+C
   - в старой папке проекта выполни: docker compose down

1. Распакуй этот архив в НОВУЮ папку и зайди в неё:
   cd pmldl_assignment1_clean

2. Убедись, что Python 3.13 установлен:
   python3.13 --version

   Если нет:
   brew install python@3.13

3. Создай чистое окружение проекта:
   ./setup_project.sh

4. Открой Docker Desktop и дождись запуска.
   Проверка:
   docker info

5. СНАЧАЛА проверь весь pipeline БЕЗ Airflow:
   ./run_pipeline.sh

   После успеха проверь:
   docker compose ps

   И открой:
   http://localhost:8000/docs
   http://localhost:8501

6. Только когда пункт 5 работает, установи Airflow:
   ./setup_airflow.sh

7. Запусти Airflow:
   ./run_airflow.sh

8. Открой:
   http://localhost:8080
   DAG: pmldl_mlops_pipeline

ВАЖНО:
- Не используй старые .venv и .airflow-venv.
- Не редактируй Dockerfile вручную.
- Docker Desktop должен быть запущен до запуска pipeline/Airflow.
- Первый Docker build может быть долгим; последующие используют cache.
